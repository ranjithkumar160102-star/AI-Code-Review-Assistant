# AI Code Review Assistant

An AI-powered full-stack web application that analyzes source code using Static Analysis and Large Language Models.

## Features

- User Authentication
- AI Code Review
- Static Code Analysis
- GitHub Repository Review
- Dashboard Analytics
- Review History
- PDF Report Download

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Recharts

### Backend
- Node.js
- Express.js
- MongoDB
- Groq API

## Installation

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Environment Variables

Create `.env`

```
MONGO_URI=
JWT_SECRET=
GROQ_API_KEY=
```
